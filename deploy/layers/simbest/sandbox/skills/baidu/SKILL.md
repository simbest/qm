# 百度热搜

本技能读取百度热搜榜（实时榜 `realtime` 或热词榜 `phrase`），用中文给用户解读当下热点，并在回答正文**之后**以 JSON 形式展示**回答中列出**的榜单条目。

## 能做什么

- 读取当前百度实时热搜或热词榜单。
- 用中文按主题（时政 / 社会 / 财经 / 娱乐 / 科技 等）归类，概述热门话题。
- 在文字回答之后追加一个 JSON 代码块，把回答中列出的条目（本次新抓取，或基于已抓取榜单的筛选 / 重排 / 子集）结构化展示给用户。

## 命令

```bash
baidu-hotlist --limit 20                  # 实时热搜，默认 20 条
baidu-hotlist --tab phrase --limit 10     # 热词榜
```

默认 `--tab realtime`、`--limit 20`（范围 1–50）。用户没有明确要热词榜时，用 `realtime`。

## 数据边界（重要）

`baidu-hotlist` 返回的每条只有：排名 `rank`、热搜词 `word`、百度搜索链接 `url`、标签 `tag`（热 / 新 / 辟谣 / 沸 / 爆）。**榜单不提供正文、摘要、来源、发布时间、热度数值。** 不要凭热搜词编造事件细节、原因或数字——热搜词只代表搜索热度，不代表事件全貌。区分“上榜”与“已证实”。榜单为空或抓取失败时直接说明，不要编造热搜。

## 输出格式

每次响应由两部分组成：

1. **正文**：简洁的中文热门话题概述，按主题归类；每条热搜给出百度搜索链接并标注标签（热 / 新 / 辟谣…），帮助用户区分“上榜”与“已核实”。
2. **JSON**：正文之后另起一行，追加一个 ```` ```json ```` 代码块，列出**本次回答中实际展示给用户的热搜条目**。
   - **只要回答里列举了热搜条目，就必须追加 JSON**——无论是本次新调 `baidu-hotlist` 抓取的，还是基于对话里已有榜单做的**筛选 / 重排 / 取子集**（例如用户追问“只看国内新闻”“只看娱乐”“按热度排”等）。
   - JSON 中的条目 = 你这一条回答里**正文实际列出的那些条目**（筛了就只列筛后子集，不要回吐整份榜单）。
   - 复用历史榜单时，条目必须取自之前 `baidu-hotlist` 的**真实返回**（`rank` / `word` / `url` / `tag`），不得凭记忆或热搜词编造。
   - JSON 只含**真实可得**的字段；不可得的字段一律**省略**（不写 `null`、不编造）。
   - 仅当本次回答**没有列举任何热搜条目**（如纯解释、闲聊，或抓取失败且无历史数据可列）时，才不输出 JSON。

### 新闻条目 JSON 字段（常见新闻字段定义）

| 字段 | 含义 | 百度热搜是否可得 |
|---|---|---|
| `rank` | 榜单排名 | ✅ 可得 |
| `title` | 标题 / 热搜词（对应工具返回的 `word`，输出时改名为 `title`） | ✅ 可得 |
| `url` | 百度搜索链接 | ✅ 可得 |
| `tag` | 标签（热 / 新 / 辟谣 / 沸 / 爆） | ✅ 可得 |
| `category` | 分类（时政 / 社会 / 财经…），由你在正文归类，属派生信息 | △ 可选，非原始数据 |
| `summary` | 内容摘要 | ❌ 榜单无正文，省略 |
| `source` | 来源媒体 | ❌ 不可得，省略 |
| `publishedAt` | 发布时间 | ❌ 不可得，省略 |
| `heat` | 热度数值 | ❌ 榜单无数值，省略 |

**输出 JSON 时**：每个 `item` 只写真实可得的字段 `rank` / `title` / `url` / `tag`（把工具返回的 `word` 改名为 `title`）。其余常见新闻字段（`summary` / `source` / `publishedAt` / `heat`）百度热搜榜单不提供，**不要写进 JSON**；分类放在正文，不要编造摘要 / 来源 / 时间 / 热度。

JSON 示例（实际输出按真实抓取结果填写；筛后子集则 `count` 与 `items` 只反映子集）：

```json
{
  "site": "百度热搜",
  "tab": "realtime",
  "fetchedAt": "2026-08-06T11:09:00.756Z",
  "count": 20,
  "items": [
    { "rank": 1, "title": "感觉全东北都在等7号", "url": "https://m.baidu.com/s?word=%E6%84%9F%E8%A7%89%E5%85%A8%E4%B8%9C%E5%8C%97%E9%83%BD%E5%9C%A8%E7%AD%897%E5%8F%B7&sa=fyb_news", "tag": "热" },
    { "rank": 2, "title": "号召领导带头休假 是大家不想休吗", "url": "https://m.baidu.com/s?word=...", "tag": "热" }
  ]
}
```
